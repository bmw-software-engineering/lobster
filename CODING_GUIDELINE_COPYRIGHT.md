# Copyright Header Guideline

Each `.py` file shall have a copyright header.
The repository license already covers all files in the repository
(unless explicitly stated otherwise for selected files), but adding the license
to each file individually is still best practice. This reduces the risk that a
file is copied or reused elsewhere without its license information.

The copyright notice shall cover the period during which the file was created and materially updated, beginning with the year of initial creation and ending with the most recent year of modification. 
This equals the relevant development timespan.

For example, if a file was created in 2022 and updated in 2024, the copyright range is `2022-2024`.
If the file is later modified in 2026, the range becomes `2022-2026` to reflect the complete development period.
